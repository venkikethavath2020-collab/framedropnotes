# Framedrops Marketing — Poster & Shorts Prompt Library

Daily-use prompt bank for AI image generation. Pick a file, copy a prompt,
generate, finish the text in Canva, post.

## How to use
1. Open the feature file you want from `instagram/` (square 1:1 posters) or
   `youtube/` (vertical 9:16 Shorts frames).
2. Each file has several ready-to-paste prompts. Copy ONE.
3. Generate the image (Midjourney / DALL·E / Ideogram / etc.).
4. **Always retype the headline, labels & footer in Canva** — AI-rendered text
   comes out misspelled. Treat the generated image as the *layout + art*, then
   overlay clean text. (Or generate the mascot + 3D icons only and assemble all
   text in Canva for pixel-perfect results.)
5. Post. Tick it off your calendar.

## BRAND SYSTEM — keep identical across every poster (this is what makes it a series)

**Palette:** deep purple `#5B2E91` · golden yellow `#F5A623` · alert red `#E1352C` · white
Background: clean white → light-purple gradient with subtle dotted texture.

**Logo (top-left):** yellow camera icon + wordmark "Frame" (black) "drops" (yellow),
tagline "Smart Photo Services" beneath.

**Footer (bottom, purple bar):** Framedrops logo left · "POWERED BY FRAMEDROPS."
(white) · yellow tagline "Professional. Transparent. Reliable." · white rounded
CTA button · centered strip with a globe icon + `www.framedrops.in`.
NOTE: website link only — do NOT add an Instagram handle in the footer.

**MASCOT (paste verbatim wherever the character appears):**
> a 3D Pixar-style cartoon photographer mascot — a cheerful young Indian man with
> brown spiky hair, big expressive eyes, warm smile, wearing a white hoodie with a
> small orange camera logo on the chest, dark grey cargo pants and white sneakers,
> holding a black DSLR camera. Smooth clay-render 3D look, glossy, vibrant.

**Layout skeleton (square poster):** logo → two-tone headline (pain/hook) →
problem cards (red ✗) → red alert bar → "THE SOLUTION" block → 5-icon feature
row (purple circles) → yellow CTA bar with 3 micro-benefits → purple footer.

**Text-render caveat:** every prompt ends with the real copy spelled out, but
expect the generator to garble it. Final text = Canva.

## Posting cadence idea
One file ≈ one week of a feature. Rotate features so the feed stays varied:
Mon agreements → Tue galleries → Wed pricing → Thu selection → Fri offer/brand.
